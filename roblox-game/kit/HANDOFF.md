# Claudeへのお引き継ぎ（Roblox対戦ゲームの組み立てと動作確認）

## お願いしたいこと
Roblox Studioで、下記の制作キットを開いて（または組み立てて）、実際に動くかどうかの動作確認をお願いします。公開までは進めないでください（非公開のまま、テストまで）。

## 素材の場所
GitHubリポジトリ「jkawamura0706-sketch/ai-sagyoba」の `roblox-game/kit/` フォルダです。

- `oshiai-arena.rbxlx` … 場所（土俵・ロビー・台）とスクリプト6本が全部入った場所ファイル。まずこれをStudioで開いてください
- `SETUP.md` … 組み立て手順。rbxlxが開けない場合は、この手順どおりに手作業で再現してください
- `scripts/` … スクリプト6本の元ファイル（GameData / PlayerData / RoundManager / ShoveServer / AbilityPads / ClientControls）

## 進め方
1. Studioで `oshiai-arena.rbxlx` を開く
2. 「ゲーム設定 → セキュリティ → StudioでAPIサービスへのアクセスを有効化」をオンにする（コイン保存の確認に必要です）
3. 「テスト」タブでプレイヤー数を2にして再生し、下の確認項目をチェックする
4. エラーが出たら、出力（Output）ウィンドウの赤い文字を、そのままユーザーに報告してください

## 確認項目（全部試してください）
- [ ] 2人そろうと全員が土俵（Ring）へ移動し、カウントダウンが表示される
- [ ] Fキー（スマホでは「おす」ボタン）で相手を押せる
- [ ] 土俵から落ちた人はロビーへ戻され、「○○が落ちた！ 残り○人」と表示される
- [ ] 最後の1人になると優勝表示が出て、コインが入る（参加+10／優勝+50）
- [ ] ロビーの台（Pad_Dash / Pad_Power / Pad_Anchor）に乗ると能力が切り替わり、Qキー（「能力」ボタン）で使える
- [ ] コード入力欄に RELEASE と入れると100コインもらえる（START は50コイン）
- [ ] 一度退出して入り直すと、コインが残っている（保存の確認）

## お約束
- 設計の数字（コイン数、コードの中身、押す力など）は勝手に変えないでください。直す必要があるときは、何をどう変えたかをユーザーに報告してください
- 公開（誰でも入れる状態にすること）は、ユーザーの指示があるまでしないでください
- 終わったら、確認項目の結果（できた／できなかった）と、直した点があればその内容をユーザーに報告してください

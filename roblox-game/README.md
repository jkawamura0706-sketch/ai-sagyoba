# 対戦ゲーム計画（Roblox）

Roblox Studioで、友達と対戦できるゲームを初めて作るための計画です。
文書「対戦ゲームの始め方（Cat Battlesに学ぶ）」をもとにまとめました。

## 目標

- Roblox Studioで、友達と対戦できるゲームを作る
- まずは「小さく作って、友達と遊べる形にする」ことが目標。完成品を急がない

## お手本：Cat Battles

- 2026年10月5日公開（制作：Cute Malt Games）
- 2026年10月20日時点で、訪問 約2,366万回／同時接続 約4.2万人／日本の急上昇 7位／1サーバー最大10人
- 遊び方（公式の説明）：ネコ同士で押したり叩いたり投げたりして、相手をリングの外へ出す。最後まで残ったネコの勝ち
- 学ぶ点：
  - ルールが1行で言える
  - 体力の計算がいらない（落ちたら負け）
  - 1試合が短く、負けてもすぐ次が遊べる
  - 動きは基本4つ＋能力1つで、覚えることが少ない

## 最初に作る範囲

- 丸い土俵 1つ
- 2〜4人で対戦
- ルールは「落ちたら負け、最後の1人が勝ち」だけ
- 動きは、押し合う・叩き合うだけ
- 試合が終わったら「もう一回」で再戦できる

## 最初は作らないもの

能力、コイン、箱（ガチャ）、チーム戦、アイテム、大きなマップ。
慣れてから、1つずつ足していく。

## 勝負の流れ

1. ロビー（待つ場所）で友達が集まる
2. 全員そろったら合図（カウントダウン）
3. 土俵に移動してスタート
4. 押し合う・叩き合う
5. 落ちた人はロビーに戻って見学
6. 最後の1人が「勝ち」と表示される
7. ロビーに戻って「もう一回」

## 流行る要素の優先順位（2026-11-12 リサーチより）

最近のヒット作の共通点は5つ：

1. 3秒で分かる一言ルール
2. 1試合が短く、負けても軽い（すぐ次が遊べる）
3. 友達と一緒だと、もっと面白くなる仕組み
4. 試合ごとにコインがたまり、集めるのは「見た目」だけ（強さと切り離す）
5. 週1回くらいのアップデート、イベント、無料コード

土台の知識：

- Robloxのおすすめは、クリック数だけでなく「入って最初の1分で辞めないか」「何日戻ってきたか」など、1人あたりの平均で評価される（小さいゲームでも不利にならない）
- 専用のサムネイル画像がないゲームは、ホームのおすすめの対象外。サムネイルとアイコンは必須
- 遊ぶ人の8割以上はスマホ。スマホのボタン操作を前提にする

### 最初から入れる

- 60秒以内に最初の試合が始まる
- 操作は3種類まで＋スマホ用ボタン
- 2人でも始まる短い試合と、待たせないロビー
- 能力は3種類（逃げる／押し出す／耐える）
- 毎試合コイン＋見た目スキン（強さは変わらない）
- フレンド参加、データの保存
- 専用サムネイルとアイコン
- 無料コードの入力欄を1つ

### 慣れてから足す

- 能力の追加（1〜2週に1つ）
- チーム戦モード
- 2つ目のマップ
- デイリークエスト（毎日の課題）
- 季節イベント
- エモートや勝利演出、ランキング表示

### 最初は入れない

- トレーディング（交換の仕組み）※Cat Battlesも公開から約1か月後の追加だった
- お金で強くなる設計
- 能力やマップの大量投入
- 本格的なランク戦
- 釣りサムネイル（おすすめに出にくくなると公式が明言）

くわしい調査結果は、モコのライブラリにあるページ「対戦ゲームの流行る要素」にまとめてあります。

## 制作キット（プログラム一式）

リサーチの優先順位をふまえて、ゲームの核になるプログラムを先に作りました。

- 組み立て手順：`kit/SETUP.md`（場所づくり → スクリプトの貼り方 → テスト → 公開とサムネイル）
- プログラム：`kit/scripts/` の6ファイル
  - GameData（コインの管理・保存、無料コード）
  - PlayerData（入室・退室時の読み書き）
  - RoundManager（試合の進行：ロビー→カウントダウン→試合→勝敗→再戦）
  - ShoveServer（「おす」攻撃と能力3種：ダッシュ／パワー／アンカー）
  - AbilityPads（ロビーの台で能力を選ぶ）
  - ClientControls（操作と画面表示、コード入力欄。スマホのボタン対応）

最初から入れた流行る要素：60秒以内に始まる試合／操作は少なく（おす＋能力）／能力3種／毎試合コイン＋保存／無料コード／専用サムネイル（別途モコから受け取り）。

# 対戦ゲーム計画（Roblox）

Roblox Studioで、友達と対戦できるゲームを初めて作るための計画です。
文書「対戦ゲームの始め方（Cat Battlesに学ぶ）」をもとにまとめました。

## 目標

- Roblox Studioで、友達と対戦できるゲームを作る
- まずは「小さく作って、友達と遊べる形にする」ことが目標。完成品を急がない

## お手本：Cat Battles

- 2026年10月5日公開（制作：Cute Malt Games）
- 2026年10月20日時点で、訪問 約2,366万回／同時接続 約4.2万人／日本の急上昇 7位／1サーバー最大10人
- 遊び方（公式の説明）：ネコ同士で押したり叩いたり投げたりして、相手をリングの外へ出す。最後まで残ったネコの勝ち
- 学ぶ点：
  - ルールが1行で言える
  - 体力の計算がいらない（落ちたら負け）
  - 1試合が短く、負けてもすぐ次が遊べる
  - 動きは基本4つ＋能力1つで、覚えることが少ない

## 最初に作る範囲

- 丸い土俵 1つ
- 2〜4人で対戦
- ルールは「落ちたら負け、最後の1人が勝ち」だけ
- 動きは、押し合う・叩き合うだけ
- 試合が終わったら「もう一回」で再戦できる

## 最初は作らないもの

能力、コイン、箱（ガチャ）、チーム戦、アイテム、大きなマップ。
慣れてから、1つずつ足していく。

## 勝負の流れ

1. ロビー（待つ場所）で友達が集まる
2. 全員そろったら合図（カウントダウン）
3. 土俵に移動してスタート
4. 押し合う・叩き合う
5. 落ちた人はロビーに戻って見学
6. 最後の1人が「勝ち」と表示される
7. ロビーに戻って「もう一回」

## 最初の手順（チェックリスト）

- [ ] ステップ1：Robloxのアカウントと Roblox Studio の用意（パソコン・無料）
- [ ] ステップ2：新しい場所を作る（ベースプレートを選ぶ）
- [ ] ステップ3：土俵を作る（円柱のパーツを平たく大きくする）
- [ ] ステップ4：スポーン（現れる場所）をロビーと土俵に置く
- [ ] ステップ5：プレイボタンで自分のキャラで歩いてみる
- [ ] ステップ6：場外に落ちたら復活（リスポーン）するか確認する
- [ ] ステップ7：保存して公開し、友達に入ってもらう
- [ ] ステップ8：2人で遊んで、土俵の広さなどを直す
- [ ] ステップ9：「○○さんの勝ち！」の表示を、スクリプトで1つだけ足す
- [ ] ステップ10：次の目標を1つ決める（例：制限時間3分）
